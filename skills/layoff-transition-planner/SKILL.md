# Layoff Transition Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants a practical LinkedIn and job-search transition plan after redundancy or a layoff Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect desired disclosure level, timeline, target roles, financial/time constraints if volunteered, severance/non-disclosure considerations, and current evidence.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify what can be shared publicly and what must remain confidential
2. Prepare a neutral profile or Open to Work communication plan
3. Organize immediate tasks, benefits and documents for the user's own verification
4. Create a paced search and network reactivation plan

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Disclosure and profile options
- Priority action checklist
- Search and outreach plan
- Follow-up cadence

## Example prompt

> I was recently laid off. Help me update LinkedIn and restart my search without sharing confidential company details.

## Edge cases and failure handling

- Do not give legal or financial advice on severance or benefits
- Do not infer fault or performance from a layoff
- Respect nondisclosure obligations.

## Quality and safety checks

- [ ] The user controls disclosure
- [ ] No confidential employer information is included
- [ ] The plan is supportive and manageable.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
