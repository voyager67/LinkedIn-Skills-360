# Resignation and Handover Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to plan a professional resignation message and knowledge handover Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for notice expectations stated by the user, desired last day, current responsibilities, active projects, audiences, and any contractual uncertainty.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Separate the resignation communication from the handover document
2. Draft a neutral resignation note with only confirmed dates
3. Inventory deliverables, owners, status, risks and access handover
4. Prepare a respectful transition conversation and avoid disclosing unnecessary reasons

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Resignation draft
- Handover checklist
- Workstream transition table
- Questions to verify with HR or contract

## Example prompt

> Help me draft a professional resignation email and handover plan for my current analyst role.

## Edge cases and failure handling

- Do not advise on legal notice compliance without jurisdiction/context
- Do not include passwords or secrets in handover materials
- Respect confidentiality and company policy.

## Quality and safety checks

- [ ] Dates are confirmed by user
- [ ] No secrets are placed in documents
- [ ] Tone stays professional.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
