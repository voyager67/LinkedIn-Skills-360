# Campus Placement Preparation Coach

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: a student wants a structured plan for campus placement tests, interviews, group discussions, or employer research Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for branch/degree, placement timeline, target companies, selection stages, syllabus or pattern, current preparation, and real project examples.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Build a stage-by-stage preparation map from official placement information
2. Prioritize technical, aptitude, communication, and project explanation practice
3. Create a company-specific question bank from public sources
4. Schedule mock sessions and feedback with measurable practice goals

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Preparation plan by stage
- Topic priority list
- Project explanation prompts
- Mock interview checklist

## Example prompt

> Prepare me for campus placements for entry-level software roles over the next six weeks.

## Edge cases and failure handling

- Selection formats vary by company and year
- Do not claim confidential or leaked test questions
- Do not recommend cheating or misrepresenting eligibility.

## Quality and safety checks

- [ ] Current hiring information is source-dated
- [ ] Practice is aligned to stated role requirements
- [ ] No guaranteed placement claim.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
