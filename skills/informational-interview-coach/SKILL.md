# Informational Interview Coach

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to request or conduct an informational conversation to learn about a role, industry, or company Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for the person's public professional context, the user's learning goal, actual connection, questions, time request, and follow-up plan.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a learning objective instead of a hidden job pitch
2. Draft a concise permission-based request for a short conversation
3. Prepare open-ended questions about work, skills and pathways
4. Create a thank-you note and learning summary without presuming referral or employment

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Request message
- Conversation agenda
- Five to eight thoughtful questions
- Thank-you and reflection template

## Example prompt

> Draft a respectful 15-minute informational interview request to an alum working in product management.

## Edge cases and failure handling

- Avoid implying personal connection that does not exist
- Make it easy to decline
- Do not ask for confidential hiring or company information.

## Quality and safety checks

- [ ] Message states the genuine learning aim
- [ ] Questions are open-ended and respectful
- [ ] No assumed referral.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
