# LinkedIn Post Writer

**Specialist:** Content Strategist  
**Category:** Brand and content

## When to use this skill

Use this workflow when: the user wants to draft or improve a LinkedIn post, announcement, lesson, project update, or professional point of view Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect the user's idea, audience, intended value, true story or evidence, desired tone, call to action if any, and topics that should remain private.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify the reader and the one useful idea the post should communicate.
2. Select a suitable structure such as lesson, project reflection, point of view, case note, or announcement.
3. Draft an authentic opening, concrete middle with context or evidence, and natural close.
4. Remove empty engagement bait, exaggerated claims, forced vulnerability, and repetitive AI-sounding phrasing.
5. Offer one polished draft and a shorter alternate opening; verify claims and ask the user to approve before posting.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Audience and single takeaway
- Draft post
- Alternate opening
- Evidence and privacy checks
- Optional visual or source suggestion

## Example prompt

> Turn this debugging lesson from my college project into a LinkedIn post for other student developers. Keep it specific, avoid fake metrics, and don't make it sound like a motivational speech.

## Edge cases and failure handling

- Do not invent customer outcomes, user counts, awards, or personal anecdotes.
- If a project contains confidential information, generalize or omit it with the user's agreement.
- Do not post or automate engagement; the user publishes manually.

## Quality and safety checks

- [ ] Post provides a real takeaway for the intended audience.
- [ ] Tone matches the user's voice and avoids formulaic hooks.
- [ ] Claims, attribution, and privacy have been checked.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
