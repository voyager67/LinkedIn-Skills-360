# Recruitment Process Scorecard Designer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a talent lead wants a scorecard for recruiting process health rather than individual candidate ranking Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for recruiting goals, stage definitions, candidate experience measures, stakeholder needs, data availability and reporting interval.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Choose process metrics tied to service quality and fairness
2. Define formula, source, denominator and owner for each metric
3. Avoid proxy measures that penalize candidate groups or role complexity
4. Create a review cadence and intervention thresholds for human discussion

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Metric dictionary
- Process scorecard
- Data ownership and limits
- Review and action protocol

## Example prompt

> Create a recruiting process scorecard covering time in stage, candidate updates, feedback completion and offer clarity.

## Edge cases and failure handling

- Do not use the scorecard as an automatic candidate ranking system
- Avoid misleading time-to-fill comparisons across different roles
- Small samples need caution.

## Quality and safety checks

- [ ] Each metric has a clear definition
- [ ] Candidate-level decisions remain human
- [ ] Data quality and cohort differences are disclosed.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
