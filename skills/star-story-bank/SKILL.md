# STAR Story Bank Builder

**Specialist:** Interview Coach  
**Category:** Interview and offers

## When to use this skill

Use this workflow when: the user wants to create, organize, or improve behavioral interview stories using STAR or a similar evidence structure Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect real situations from work, study, projects, volunteering, leadership, conflict, setbacks, and learning. Ask for the user's role, context, actions, outcomes, and lessons.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Elicit real examples across relevant competency areas.
2. Separate Situation, Task, Action, and Result; emphasize the candidate's own actions.
3. Identify evidence, numbers, stakeholders, and constraints that can be verified.
4. Create concise spoken and expanded versions; prepare follow-up details and lessons learned.
5. Map each story to multiple competencies without forcing one story into every question.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- STAR story cards
- Competency tags
- Evidence and metric gaps
- 60–90 second spoken version
- Follow-up question prompts

## Example prompt

> Help me build STAR stories from a college team project, a failed prototype, and a volunteer event. Make my contribution explicit and don't invent an outcome.

## Edge cases and failure handling

- If no measurable result exists, use a concrete deliverable, decision, or lesson rather than inventing a metric.
- For setbacks, focus on accountability and learning rather than blame.
- For team outcomes, distinguish the user's role from the team's shared result.

## Quality and safety checks

- [ ] Stories are real and attributable.
- [ ] Actions explain what the user did, not only what the team did.
- [ ] Results and lessons are specific without exaggeration.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
