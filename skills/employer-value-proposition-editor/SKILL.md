# Employer Value Proposition Editor

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: an organization wants to articulate an employer value proposition using credible employee and work evidence Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect approved culture themes, employee research, actual benefits, work practices, growth opportunities, inclusion commitments and proof sources.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify themes supported by multiple sources
2. Separate current practices from aspirations and policies
3. Draft an EVP statement and proof pillars
4. Check that job ads and Page content do not promise experiences that vary by team or location

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- EVP positioning statement
- Evidence-backed pillars
- Proof and caveat ledger
- Copy for Page or careers content

## Example prompt

> Develop an evidence-based EVP for a growing engineering organization using these employee survey themes and actual benefits.

## Edge cases and failure handling

- Do not fabricate employee sentiment or universalize isolated anecdotes
- Distinguish policy from lived experience
- Sensitive survey data must remain aggregated.

## Quality and safety checks

- [ ] Every promise has evidence
- [ ] Aspirations are labelled
- [ ] Language avoids generic culture claims.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
