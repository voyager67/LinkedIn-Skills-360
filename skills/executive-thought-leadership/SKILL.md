# Executive Thought Leadership Strategist

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: an executive wants to communicate expertise and organizational perspective through credible LinkedIn content Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for executive role, actual areas of expertise, audience, approved strategic themes, firsthand stories, sources, voice, and communications review requirements.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define one or two defensible points of view grounded in the executive's experience
2. Build a topic map linking company context and public value
3. Draft content that adds insight rather than repeating corporate slogans
4. Create a fact-check and approval sequence for sensitive claims

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Positioning and audience
- Thought-leadership pillars
- Draft content themes and sample post
- Evidence and approval checklist

## Example prompt

> Create a thought-leadership plan for a CTO discussing responsible AI adoption, based only on these approved facts.

## Edge cases and failure handling

- Do not invent personal opinions or experiences for the executive
- Flag financial, regulatory, product roadmap and personnel claims for review
- Avoid impersonation without authorization.

## Quality and safety checks

- [ ] Voice reflects the executive's stated views
- [ ] Claims are approved and sourced
- [ ] Risky topics are escalated.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
