# LinkedIn Newsletter Strategy

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: the user wants to launch, position, plan, or improve a LinkedIn newsletter Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect reader persona, editorial promise, topic authority, cadence, source material, distribution goals, and any existing newsletter data.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a focused reader and repeatable editorial promise
2. Choose a realistic cadence and recurring issue structure
3. Plan a small set of evidence-led issue themes with primary sources
4. Draft subscription positioning, issue outline and an editorial review checklist

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Newsletter promise and audience
- Cadence and issue architecture
- 4–8 issue editorial map
- Launch checklist and sample issue outline

## Example prompt

> Design a monthly LinkedIn newsletter for early-career data analysts focused on practical portfolio skills.

## Edge cases and failure handling

- Newsletter availability and analytics vary by account and region
- Do not claim subscriber growth or deliverability outcomes
- Avoid republishing material without permission.

## Quality and safety checks

- [ ] Each issue offers a clear reader benefit
- [ ] Sources and author expertise are appropriate
- [ ] Cadence is sustainable.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
