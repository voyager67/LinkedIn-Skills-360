# Recommendation Request Coach

**Specialist:** Profile Optimizer  
**Category:** Profile and reputation

## When to use this skill

Use this workflow when: the user wants to ask a former manager, peer, client, mentor, or collaborator for a LinkedIn recommendation Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect the real relationship, shared work, requested perspective, timing, recipient constraints, and two or three concrete projects or behaviours the recipient personally observed.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Confirm that the recipient can speak from direct experience
2. Select one narrow theme rather than asking for a generic endorsement
3. Draft a respectful request that offers factual prompts but does not dictate praise
4. Add a graceful decline option and a reminder plan that does not pressure the recipient

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Relationship and evidence basis
- Personalized request message
- Optional memory prompts
- Low-pressure follow-up and stop condition

## Example prompt

> Help me ask my former project lead for a recommendation focused on my collaboration and frontend contribution.

## Edge cases and failure handling

- If the relationship is weak or stale, suggest reconnecting before making the request
- Never ask someone to claim results they did not observe.

## Quality and safety checks

- [ ] The request is specific and easy to decline
- [ ] Prompts are memory aids, not scripted testimonials
- [ ] No claims are attributed to the recipient without their review.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
