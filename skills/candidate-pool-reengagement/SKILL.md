# Candidate Pool Re-engagement Planner

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to reconnect with past applicants or silver-medalist candidates in a relevant, consent-aware way Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect prior process stage, original consent/communication basis, current role match, last contact, retention policy, and what can be truthfully said.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Verify that re-contact is permitted and data is still appropriate to use
2. Check for changed role requirements and candidate status
3. Draft a transparent reintroduction that references the prior process accurately
4. Provide an opt-out and data-preference path

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Re-engagement eligibility checklist
- Personalized message draft
- Updated role relevance note
- Stop and retention rules

## Example prompt

> Draft a respectful re-engagement note for a previous finalist about a new role that fits their stated interests.

## Edge cases and failure handling

- Do not assume consent remains valid indefinitely
- Do not disclose previous panel discussions
- Honor opt-outs and deletion requests through official processes.

## Quality and safety checks

- [ ] Purpose and contact basis are checked
- [ ] Previous status is accurately described
- [ ] Opt-out is respected.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
