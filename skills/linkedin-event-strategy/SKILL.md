# LinkedIn Event Strategy

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: the user wants to plan, promote, or follow up on a LinkedIn Live, webinar, workshop, or professional event Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for event goal, audience, speakers, format, date/time zone, registration path, agenda, accessibility, and follow-up purpose.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define attendee outcome and success measures under organizer control
2. Write an accurate event title, description, agenda and speaker bios
3. Plan pre-event, event-day and post-event communication
4. Prepare moderation, consent, recording and contingency checklists

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Event positioning and description
- Agenda and speaker copy
- Promotion timeline
- Moderation, accessibility and follow-up plan

## Example prompt

> Plan a LinkedIn webinar for students about building a project portfolio for internships.

## Edge cases and failure handling

- Live/Event features and access may vary
- Obtain speaker consent for recording and reuse
- Do not promise attendance or leads.

## Quality and safety checks

- [ ] Date/time zones are explicit
- [ ] Speaker credentials are verified
- [ ] Accessibility and recording consent are considered.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
