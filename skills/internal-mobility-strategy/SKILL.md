# Internal Mobility Strategy

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to use LinkedIn and professional materials to explore a role change inside their current organization Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for current role, target internal role, public/org knowledge the user can share, evidence, stakeholders, policies, and confidentiality constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map target-role requirements to demonstrated internal work
2. Identify transferable projects and development gaps
3. Plan discreet, policy-aligned conversations with manager or internal contacts
4. Draft a positioning summary and development discussion agenda

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Internal target-role map
- Evidence and gap analysis
- Stakeholder conversation plan
- Development proposal

## Example prompt

> Help me move from QA analyst to product operations internally using my release coordination experience.

## Edge cases and failure handling

- Internal roles and processes may be confidential
- Do not recommend bypassing company policy
- Do not assume manager support.

## Quality and safety checks

- [ ] Evidence distinguishes direct and adjacent experience
- [ ] Stakeholder plan is respectful
- [ ] Confidential details are protected.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
