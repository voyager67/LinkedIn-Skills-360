# Document Carousel Storyboard

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: the user wants a LinkedIn document/carousel outline that teaches a concept or explains a project Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect audience, learning objective, verified content, source assets, slide constraints, visual identity, and CTA preference.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Create a narrative arc with one idea per slide
2. Draft cover, problem, explanation, example, takeaway and close
3. Check the flow at thumbnail scale and for mobile readability
4. Add source/attribution and export checklist; do not fabricate design outcomes

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Slide-by-slide storyboard
- On-slide copy and visual direction
- Cover options and CTA
- Accessibility and source checklist

## Example prompt

> Create a 7-slide carousel explaining how students can build a credible software project portfolio.

## Edge cases and failure handling

- Platform document specifications can change
- Do not reuse copyrighted charts or images without permission
- Avoid dense text and unsupported statistics.

## Quality and safety checks

- [ ] Each slide advances the teaching goal
- [ ] Visual directions are feasible
- [ ] Sources and alt-text considerations are included.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
