# Recruiter Job Description Writer

**Specialist:** Recruiter Assistant  
**Category:** Recruiting

## When to use this skill

Use this workflow when: the user wants to write or improve a job description, role scorecard, or hiring brief Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect business need, outcomes, responsibilities, required and preferred qualifications, level, location/work arrangement, compensation transparency constraints, reporting line, and interview process.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify why the role exists and what outcomes define success in the first 6–12 months.
2. Separate essential qualifications from trainable or preferred ones.
3. Write responsibilities using concrete actions and realistic scope; avoid inflated wish lists.
4. Include transparent logistics, compensation information where permitted, accessibility and accommodation route, and a concise hiring process.
5. Review for exclusionary language, contradictory requirements, and criteria not genuinely needed for the work.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Role purpose and outcomes
- Job description draft
- Required vs preferred criteria
- Interview process outline
- Ambiguities and inclusion review

## Example prompt

> Write a junior data analyst job description from this team brief. Distinguish essential skills from nice-to-haves and do not require an arbitrary degree if equivalent project experience is acceptable.

## Edge cases and failure handling

- If compensation or location is undecided, mark it as an open decision rather than inventing details.
- Avoid age-coded, gender-coded, or prestige-only requirements.
- Do not imply legal compliance without jurisdiction-specific review.

## Quality and safety checks

- [ ] Every requirement connects to the work.
- [ ] Responsibilities and level are realistic.
- [ ] Language welcomes equivalent evidence and accessible participation.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
