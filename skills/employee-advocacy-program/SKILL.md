# Employee Advocacy Program Designer

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: a company wants a voluntary and credible employee advocacy program for LinkedIn Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect company goals, audiences, content themes, employee consent, available enablement, brand/legal constraints, and measurement approach.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a voluntary purpose and guardrails
2. Create participation options beyond reposting, including original expertise
3. Provide source facts and optional copy that employees can personalize
4. Set privacy, disclosure, approval and measurement expectations

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Program charter
- Participation guidelines
- Content starter pack
- Measurement and feedback plan

## Example prompt

> Design an employee advocacy program for a 100-person technology company without making employees post mandatory promotional content.

## Edge cases and failure handling

- Do not require personal account activity as employment condition
- Disclose incentives where relevant
- Respect confidential information and employee choice.

## Quality and safety checks

- [ ] Participation is voluntary
- [ ] Employee voice is preserved
- [ ] No misleading or coordinated fake engagement.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
