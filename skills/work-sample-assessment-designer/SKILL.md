# Work Sample Assessment Designer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a hiring team wants a practical exercise or work sample that reflects real role tasks Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for role outcomes, candidate level, task context, time budget, accessible format, evaluation criteria, and what can be shared publicly.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Choose a representative task with realistic constraints
2. Set a fair time budget and provide consistent instructions
3. Define rubric anchors before reviewing submissions
4. Protect candidate ownership, data and IP; clarify whether exercise work will be used commercially

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Work sample brief
- Candidate instructions
- Rubric and anchor examples
- Accessibility, time and IP safeguards

## Example prompt

> Design a 60-minute work sample for a junior data analyst role using synthetic data only.

## Edge cases and failure handling

- Do not request unpaid productive work
- Avoid inaccessible or excessive tasks
- Do not use real customer data
- Clarify ownership and use.

## Quality and safety checks

- [ ] Task reflects actual job needs
- [ ] Candidates receive equal instructions and time
- [ ] Rubric is defined in advance.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
