# Profile Visitor Conversion Path Designer

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: a professional wants to turn profile visits into appropriate conversations, service enquiries, or career opportunities Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for profile goal, audience, desired next step, contact route, proof assets, response capacity, and any platform CTA options currently visible.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map the visitor journey from headline to About, Featured, experience and contact path
2. Identify ambiguity or friction at each stage
3. Draft one primary CTA and supporting proof
4. Check that the next step is realistic and the user can respond promptly

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Conversion path map
- Section-level CTA recommendations
- Copy-ready call to action
- Follow-up capacity checklist

## Example prompt

> Improve my LinkedIn profile so potential consulting clients know what to do next without sounding salesy.

## Edge cases and failure handling

- Do not promise conversion-rate improvements
- CTA and button availability can vary
- Avoid collecting unnecessary sensitive lead data.

## Quality and safety checks

- [ ] The visitor path is coherent
- [ ] CTA is specific and truthful
- [ ] The user can fulfill the promise.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
