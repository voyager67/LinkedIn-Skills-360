# LinkedIn Learning Program Designer

**Specialist:** Career Growth Coach  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: an organization or learning team wants to curate LinkedIn Learning content for a workforce development program Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect target learner groups, competency framework, business goals, course licence, available content, accessibility needs, time budget and evaluation approach.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define learning outcomes and intended proficiency
2. Map courses to competencies and role pathways
3. Blend course time with applied practice and manager reinforcement
4. Plan cohort communication, access checks and feedback
5. Measure learning evidence rather than logins alone

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Learning program blueprint
- Course-to-competency map
- Cohort schedule and practice tasks
- Access and evaluation plan

## Example prompt

> Design a LinkedIn Learning program for onboarding analysts to SQL, dashboards and stakeholder communication.

## Edge cases and failure handling

- Organization-specific libraries and licenses vary
- Do not imply a course is available without checking access
- Completion rates alone do not establish competence.

## Quality and safety checks

- [ ] Program ties learning to workplace tasks
- [ ] Access and accessibility are checked
- [ ] Evaluation includes demonstrated practice.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
