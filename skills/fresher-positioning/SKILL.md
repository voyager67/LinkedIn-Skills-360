# Fresher and Recent Graduate Positioning

**Specialist:** Career Transition Advisor  
**Category:** Career-stage variants

## When to use this skill

Use this workflow when: the user is a fresher or recent graduate and wants to position themselves for entry-level roles without extensive professional experience Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect degree or training, graduation date, projects, internships, coursework, certifications, volunteer experience, strongest skills, target role, and location.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify the most relevant evidence for the target entry-level role.
2. Translate academic and project work into employer-readable skills and outcomes.
3. Distinguish hands-on experience, guided learning, and theoretical exposure.
4. Draft headline, About, resume summary, and project bullets with realistic scope.
5. Create a practical plan for proof-building, interview practice, and targeted applications.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Target role positioning
- Profile summary and headline
- Project/experience bullets
- Evidence gaps
- Entry-level application plan

## Example prompt

> Create an entry-level cybersecurity LinkedIn profile for a recent graduate with networking labs, a home lab, and one internship. Keep practical exposure and professional experience distinct.

## Edge cases and failure handling

- If the user lacks formal experience, do not frame that as a personal failure.
- Do not upgrade classroom familiarity into job-ready expertise without proof.
- Where relevant, explain how to present a gap or delayed graduation accurately.

## Quality and safety checks

- [ ] Experience level is transparent.
- [ ] Relevant proof is foregrounded.
- [ ] Claims are suitable for a junior role and supported by examples.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
