# LinkedIn Sponsored Message Copy Review

**Specialist:** LinkedIn Ads Strategist  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: the user wants to review paid LinkedIn Sponsored Messaging or Conversation Ad copy for clarity and relevance Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect campaign objective, paid format, audience, offer, sender identity, approved personalization fields, CTA, destination and disclosure requirements.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Check that the recipient has a clear reason to see the message
2. Make sender identity and commercial purpose transparent
3. Write a concise message with one clear CTA
4. Review claims, personalization, frequency and opt-out/choice mechanism
5. Verify current format and policy requirements in Campaign Manager

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Message copy and CTA variants
- Personalization rationale
- Claims and disclosures checklist
- Review items for platform policy

## Example prompt

> Review this paid LinkedIn message ad for a webinar invitation. Make it clear and not manipulative.

## Edge cases and failure handling

- Paid sponsored messaging is distinct from manual networking messages
- Personalization must not expose or infer sensitive information
- Ad formats and controls may change.

## Quality and safety checks

- [ ] Commercial intent is transparent
- [ ] Personalization is business-relevant
- [ ] No false urgency or unsupported promise.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
