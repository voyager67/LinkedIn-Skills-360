# LinkedIn Company Page Audit

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: a page admin or marketer wants to assess the clarity, completeness, credibility, and usefulness of a LinkedIn Company Page Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Request Page text or screenshots, company website, target audiences, service lines, hiring needs, and the user's authorized observations.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Review identity, tagline, About, website, specialties, locations and CTA
2. Check consistency with official company sources and current offers
3. Evaluate trust signals, accessibility, audience pathways and content coherence
4. Prioritize changes by importance and ease, noting admin settings the user must inspect

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Page completeness review
- Message and consistency audit
- Priority fixes
- Evidence and admin-action checklist

## Example prompt

> Audit our company LinkedIn Page for customer clarity and employer-brand credibility using this text and website.

## Edge cases and failure handling

- Do not imply admin access or change Page settings
- Company facts must be verified from official sources
- Some Page fields and features vary by tier/region.

## Quality and safety checks

- [ ] Recommendations match the business and audience
- [ ] Claims are sourceable
- [ ] No Page change is claimed as completed.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
