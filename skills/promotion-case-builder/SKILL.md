# Promotion Case Builder

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to prepare a promotion case or career progression discussion using documented outcomes Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for role expectations, review period, work outcomes, feedback, team contribution, promotion criteria, and confidential information boundaries.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map achievements to stated level expectations
2. Separate individual contribution, team result, and contextual factors
3. Identify missing evidence and feedback
4. Draft a concise case and discussion plan with development commitments

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Promotion evidence matrix
- Impact narrative
- Gaps and corroboration needed
- Manager discussion agenda

## Example prompt

> Help me build a promotion case from these project outcomes and feedback against my company's next-level expectations.

## Edge cases and failure handling

- Do not fabricate performance metrics or manager statements
- Handle confidential team or compensation data carefully
- Do not infer promotion guarantee.

## Quality and safety checks

- [ ] Claims map to real evidence
- [ ] Attribution is fair
- [ ] The case acknowledges development gaps.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
