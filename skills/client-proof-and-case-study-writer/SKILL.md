# Client Proof and Case Study Writer

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: a freelancer, consultant, or company wants to turn client work into a credible LinkedIn case study Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect project scope, baseline/context, methods, deliverables, measured outcomes, client permission, anonymization needs, and attribution.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Confirm permission and acceptable public detail
2. Separate measured outcomes from qualitative feedback
3. Document baseline, intervention, timeframe and confounders
4. Draft a concise story with evidence and attribution limits
5. Request client fact review before publication

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Case-study outline
- Draft LinkedIn case study
- Claim/metric source ledger
- Permission and redaction checklist

## Example prompt

> Turn this completed web-design project into a LinkedIn case study, using only approved metrics and anonymizing the client.

## Edge cases and failure handling

- No public mention of a client without permission
- Correlation does not establish impact
- Do not fabricate testimonials or before/after results.

## Quality and safety checks

- [ ] Metrics include source, period and baseline
- [ ] Client consent is documented by user
- [ ] Anonymization is robust enough for intended audience.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
