# Alumni Networking Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to identify and approach alumni for career learning, mentorship, or opportunity discovery Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect institution, program/year if relevant, target field, public alumni information available, user's evidence and reason for outreach.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define the target alumni segments and the reason each can help
2. Create a transparent search strategy using permitted alumni/community directories
3. Prepare personalized but factual outreach variants
4. Track conversations, learning, and appropriate follow-up manually

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Alumni segment map
- Search keywords and filters
- Outreach drafts
- Conversation and follow-up tracker fields

## Example prompt

> Create an alumni outreach plan to learn about cybersecurity careers from graduates of my college.

## Edge cases and failure handling

- Do not scrape alumni lists or collect private contact details
- Shared institution does not imply relationship
- Do not spam multiple alumni with identical messages.

## Quality and safety checks

- [ ] Personalization is evidence-based
- [ ] Data collection is minimal and permitted
- [ ] Outreach volume is reasonable.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
