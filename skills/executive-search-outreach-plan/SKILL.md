# Executive Search Outreach Planner

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants a discreet, high-context outreach plan for senior or executive talent Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect approved role mandate, leadership outcomes, confidentiality boundary, target profile, public evidence, recruiter identity, and contact permissions.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Translate the mandate into a compelling but accurate opportunity thesis
2. Identify relevant executive backgrounds from permitted public research
3. Draft discreet, personalized first contact without disclosing confidential client details
4. Plan a limited follow-up and referral path with strict stop conditions

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Executive role value proposition
- Target profile criteria
- Discreet outreach draft
- Follow-up and confidentiality rules

## Example prompt

> Prepare an executive search outreach note for a VP Engineering opportunity without revealing the client name at first contact.

## Edge cases and failure handling

- Do not misrepresent recruiter identity or mandate
- Do not fabricate compensation, reporting line or board sponsorship
- Honor confidentiality and no-contact requests.

## Quality and safety checks

- [ ] Mandate details are approved
- [ ] Outreach is accurate and discreet
- [ ] No automated bulk contact.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
