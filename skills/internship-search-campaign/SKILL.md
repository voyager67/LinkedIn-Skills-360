# Internship Search Campaign Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: a student or early-career user wants to plan an internship search from target selection to follow-up Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect degree/year, practical projects, preferred role, location, availability dates, eligibility, resume, and academic schedule.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Create role families and a shortlist rubric
2. Identify campus, company, alumni, community, and public posting channels
3. Prepare a project-led profile and application evidence pack
4. Schedule applications, networking and follow-ups around study commitments

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Internship target map
- Weekly outreach/application plan
- Evidence pack checklist
- Follow-up schedule

## Example prompt

> Build a 4-week internship search campaign for a second-year IT student with two web projects and no previous internship.

## Edge cases and failure handling

- Do not imply internship eligibility without checking the posting
- Unpaid, exploitative, or fee-based opportunities need scrutiny
- Different countries have different student work rules.

## Quality and safety checks

- [ ] Student experience is represented accurately
- [ ] Academic workload is respected
- [ ] Eligibility unknowns are surfaced.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
