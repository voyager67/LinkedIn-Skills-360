# Accessible Job Advertisement Rewriter

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a hiring team wants to make a LinkedIn job post clearer, more accessible, and easier to assess Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect the current job ad, role outcomes, essential qualifications, location/work model, compensation disclosure, application instructions and accessibility commitments.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Rewrite in plain language with clear sections
2. Separate essential criteria from preferences
3. Replace vague traits with observable responsibilities
4. Add confirmed logistics, application steps and accommodation contact route where approved

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Revised job post
- Essential/preferred criteria split
- Missing logistics checklist
- Accessibility review notes

## Example prompt

> Rewrite this job post for a junior software tester to make it clearer and reduce unnecessary degree requirements.

## Edge cases and failure handling

- Do not invent pay range, work model or accommodation process
- Check platform character/field limits before posting
- Keep legal notices under HR review.

## Quality and safety checks

- [ ] Job information is complete or gaps are flagged
- [ ] Requirements are job-related
- [ ] Plain language is used.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
