# LinkedIn Showcase Page Strategy

**Specialist:** Page Marketing Strategist  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: a company wants to determine whether to create and manage a LinkedIn Showcase Page for a product, business unit or initiative Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for parent Page, distinct audience, business purpose, content capacity, brand relationship, analytics needs, and current Page structure.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Test whether the audience and value proposition are distinct enough to justify a separate Page
2. Compare Showcase Page benefits with posting from the parent Page
3. Define ownership, content cadence, moderation and cross-linking
4. Set success measures and a review/retirement condition

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Page architecture recommendation
- Audience and editorial purpose
- Ownership and governance
- Success and consolidation criteria

## Example prompt

> Should we create a Showcase Page for our enterprise product or keep the content on the parent Company Page? Evaluate the trade-offs.

## Edge cases and failure handling

- Showcase Page capabilities and metrics can change
- Separate Pages require ongoing content and moderation capacity
- Do not duplicate content without a purpose.

## Quality and safety checks

- [ ] A new Page has a distinct audience rationale
- [ ] Costs and maintenance are visible
- [ ] No unsupported reach forecast.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
