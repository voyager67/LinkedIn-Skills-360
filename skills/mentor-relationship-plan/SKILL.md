# Mentor Relationship Plan

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to find, approach, or maintain a productive mentoring relationship on LinkedIn Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for the user's developmental goal, mentor profile/context supplied by the user, existing relationship, time horizon, and what they can offer or contribute.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a narrow mentoring objective and expected cadence
2. Identify mentors by relevant experience rather than status alone
3. Draft a clear low-pressure invitation or ask
4. Set boundaries, review milestones, and a graceful close or pause plan

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Mentoring objective
- Mentor fit criteria
- Invitation message
- First-meeting agenda and review cadence

## Example prompt

> Help me approach a senior cloud engineer for occasional career guidance without sounding entitled.

## Edge cases and failure handling

- Do not describe a stranger as a mentor before agreement
- Mentoring is voluntary and may not be reciprocal
- Avoid repeated follow-ups after no response.

## Quality and safety checks

- [ ] The request is bounded and respectful
- [ ] The expected commitment is clear
- [ ] No relationship is fabricated.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
