# LinkedIn University Page and Alumni Strategy

**Specialist:** Career Growth Coach  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: a university or student career team wants to use its LinkedIn University Page and alumni network responsibly Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect institution identity, program/department goals, alumni audiences, verified outcomes, event calendar, staff owners and permitted data sources.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define the student/alumni outcome and institutional purpose
2. Plan program, faculty, event and career content from approved facts
3. Design alumni engagement and mentorship pathways using voluntary participation
4. Create a privacy-aware outcome tracking plan
5. Check the current Page and alumni tools available to the institution

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- University Page content plan
- Alumni engagement pathways
- Event and mentorship ideas
- Consent and measurement checklist

## Example prompt

> Create an alumni engagement plan for a university engineering department using LinkedIn, without scraping alumni contact lists.

## Edge cases and failure handling

- Institution Page eligibility and capabilities may vary
- Do not scrape or export alumni personal data
- Employment outcomes must not be inflated or presented without context.

## Quality and safety checks

- [ ] Alumni participation is voluntary
- [ ] Claims are backed by institutional evidence
- [ ] Data collection is minimal.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
