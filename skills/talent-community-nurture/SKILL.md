# Talent Community Nurture Planner

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to maintain respectful engagement with a consenting talent community Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for community purpose, opt-in status, audience segments, content value, contact cadence, data retention and unsubscribe/exit process.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define what value members receive
2. Segment by professional interest only where appropriate and permitted
3. Plan helpful updates, learning events and role alerts
4. Create consent, preference, unsubscribe and inactive-member review rules

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Community value proposition
- Content and event cadence
- Consent and preference workflow
- Feedback and exit process

## Example prompt

> Design a quarterly nurture plan for an opt-in community of data engineering professionals.

## Edge cases and failure handling

- Do not use scraped contacts or inferred consent
- Avoid sensitive personal segmentation
- Do not send messages automatically.

## Quality and safety checks

- [ ] Opt-in basis and exit route are clear
- [ ] Updates are useful and proportionate
- [ ] Data retention is minimized.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
