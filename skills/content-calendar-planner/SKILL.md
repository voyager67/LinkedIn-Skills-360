# LinkedIn Content Calendar Planner

**Specialist:** Content Strategist  
**Category:** Brand and content

## When to use this skill

Use this workflow when: the user wants a LinkedIn content plan, posting calendar, content pillars, or repeatable editorial workflow Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect audience, goals, topics, expertise, available source material, posting capacity, preferred formats, and any launch or event dates.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a small set of content pillars connected to the user's real expertise and audience needs.
2. Generate topic ideas from projects, lessons, useful explanations, questions, and credible sources.
3. Assign each idea a format and an intended reader benefit.
4. Build a realistic calendar based on available time; leave space for timely or spontaneous content.
5. Add a lightweight review method using meaningful feedback and learning, not vanity metrics alone.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Audience and content goals
- 3–5 content pillars
- Calendar with topic, format, takeaway, and source/evidence
- Production checklist
- Review questions

## Example prompt

> Plan a four-week content calendar for a student interested in AI engineering. I can write one post per week and want to share real learning, not pretend to be an expert.

## Edge cases and failure handling

- Do not imply a guaranteed posting cadence or timing improves reach without evidence.
- If the user has little source material, include a plan to create or learn before publishing.
- Avoid disclosing confidential employer, client, or teammate information.

## Quality and safety checks

- [ ] Every topic connects to a real capability or source.
- [ ] Cadence is realistic.
- [ ] Success measures include usefulness and conversation quality, not guaranteed reach.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
