# Lead Qualification and Discovery Planner

**Specialist:** Sales Development Strategist  
**Category:** Sales, partnerships and business development

## When to use this skill

Use this workflow when: the user wants to prepare discovery questions to assess whether a prospect has a real business need and fit Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect product/service scope, ideal customer profile, known context, buyer role, hypotheses, buying process if known, and disqualification criteria.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Translate product fit into problem hypotheses, not assumptions
2. Prepare open-ended questions about current process, impact, constraints and alternatives
3. Define qualification evidence and unknowns
4. Create a next-step decision rubric that respects the prospect's own priorities

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Discovery agenda
- Open questions by theme
- Qualification evidence checklist
- Next-step options and disqualifiers

## Example prompt

> Prepare discovery questions for a conversation with a small retailer considering inventory management software.

## Edge cases and failure handling

- Do not pressure or mislead the prospect
- Avoid collecting sensitive customer or employee data
- A qualification framework is not a claim about the prospect's finances.

## Quality and safety checks

- [ ] Questions are open and neutral
- [ ] Fit is evidence-based
- [ ] A no-fit result is treated respectfully.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
