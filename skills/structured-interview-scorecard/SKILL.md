# Structured Interview Scorecard

**Specialist:** Recruiter Assistant  
**Category:** Recruiting

## When to use this skill

Use this workflow when: the user wants an interview scorecard, competency-based questions, or consistent evaluation guidance for a hiring panel Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect approved job description, role level, competencies, interview stage, question format, scoring scale, and accommodations/process constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Select a small set of competencies directly tied to role outcomes.
2. Write behaviorally anchored questions and consistent probes for each competency.
3. Define observable scoring anchors before interviews, including what insufficient, developing, and strong evidence looks like.
4. Create a structured note space for candidate evidence and interviewer observations.
5. Explain how panelists should calibrate and discuss differences without turning scores into automatic decisions.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Competency map
- Interview questions and probes
- Anchored scoring guide
- Evidence note template
- Panel calibration guidance

## Example prompt

> Build a structured scorecard for a junior backend engineer interview. Assess debugging, API fundamentals, collaboration, and learning using observable anchors.

## Edge cases and failure handling

- Do not ask for irrelevant personal or protected information.
- Provide accessible alternatives and reasonable accommodations through the employer's process.
- If criteria are not tied to job outcomes, revise before interviews.

## Quality and safety checks

- [ ] Questions measure job-related competencies.
- [ ] Anchors are observable and consistent.
- [ ] Scores inform, but do not replace, human judgement.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
