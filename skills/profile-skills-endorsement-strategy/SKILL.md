# Skills and Endorsement Strategy

**Specialist:** Profile Optimizer  
**Category:** Profile and reputation

## When to use this skill

Use this workflow when: the user wants to curate their LinkedIn skills section or plan authentic endorsement requests Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect target roles, actual skills, evidence such as projects or work, proficiency level, and skills that should not be represented as strengths.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map role-relevant skills to demonstrable evidence
2. Separate practiced skills from exposure or coursework
3. Recommend an ordered, focused skill inventory
4. Suggest specific colleagues who can genuinely attest to a skill and prepare respectful requests

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Prioritized skills inventory
- Evidence map and confidence labels
- Optional endorsement request drafts
- Gaps to build or verify

## Example prompt

> Help me prioritize LinkedIn skills for entry-level data analyst roles using my course and project evidence.

## Edge cases and failure handling

- Do not purchase, exchange, or fabricate endorsements
- Platform limits and display behaviour should be checked in current settings.

## Quality and safety checks

- [ ] Every listed skill has a defensible evidence level
- [ ] Endorsement requests target firsthand observers
- [ ] No algorithm or search-rank guarantee.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
