# Reference Check Planner

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter or candidate wants to plan a fair, consistent professional reference check Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for role competencies, reference consent, relationship context, standardized questions, jurisdiction/policy requirements, and data handling rules.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Confirm permission and relevance of each reference
2. Use the same job-related question set for comparable candidates
3. Record direct observations separately from opinion
4. Provide a secure, minimal record and retention reminder

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Reference request and consent checklist
- Standard questions
- Evidence capture form
- Limitations and escalation notes

## Example prompt

> Design a reference-check script for a team lead role focused on coaching and delivery accountability.

## Edge cases and failure handling

- Never contact an unapproved reference
- Do not ask about protected or irrelevant personal matters
- Follow organization and local policies.

## Quality and safety checks

- [ ] Consent and relevance are confirmed
- [ ] Questions are consistent and job-related
- [ ] Records are minimized.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
