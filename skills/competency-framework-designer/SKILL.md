# Job-related Competency Framework Designer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: the user wants to define competencies and observable evidence for a role or hiring process Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for role outcomes, level, work examples, team context, constraints, and existing competency definitions if any.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Derive competencies from real role tasks and success outcomes
2. Define observable positive and weak evidence at the correct level
3. Distinguish trainable skills from day-one requirements
4. Validate that each competency can be assessed consistently in an interview or work sample

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Competency framework
- Behavioural evidence anchors
- Assessment method per competency
- Gaps and validation questions

## Example prompt

> Design a competency framework for a customer success associate using these role responsibilities.

## Edge cases and failure handling

- Avoid vague labels such as culture fit or communication style without behavioural definitions
- Do not include protected or irrelevant personal traits
- Level anchors need human validation.

## Quality and safety checks

- [ ] Every competency is job-related
- [ ] Evidence is observable
- [ ] Assessment methods are proportionate to role.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
