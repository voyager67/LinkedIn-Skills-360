# LinkedIn Ads Creative Brief

**Specialist:** LinkedIn Ads Strategist  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: the user wants to prepare paid LinkedIn ad creative across image, video, document, carousel or message formats Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for campaign objective, audience, offer, proof, landing destination, approved brand assets, format constraints, and review owners.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Create a single audience insight and message hierarchy
2. Translate the message into format-specific creative directions
3. Write headline, body and CTA variants within verified current limits
4. Identify proof, disclosures, accessibility and brand approvals
5. Produce a test matrix that changes one major variable at a time

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Creative strategy and message hierarchy
- Format-specific copy and directions
- CTA variants
- Test matrix and approval checklist

## Example prompt

> Prepare three LinkedIn ad creative concepts for a B2B webinar about supply-chain analytics, using only these approved facts.

## Edge cases and failure handling

- Do not fabricate customer logos, testimonials or quantified outcomes
- Check exact character limits and supported formats before launch
- Ensure rights to images and video.

## Quality and safety checks

- [ ] Creative is aligned to the objective
- [ ] Claims are evidenced
- [ ] Variants are testable and accessible.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
