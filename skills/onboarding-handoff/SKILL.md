# Recruitment-to-Onboarding Handoff

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to transfer an accepted candidate's relevant hiring context to the onboarding team Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect only approved role-relevant information, confirmed offer terms, start date, agreed accommodations/process needs, equipment dependencies and handoff owner.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Separate hiring evidence from onboarding tasks
2. Transfer only necessary information through approved channels
3. Confirm role, manager, start date, location and dependencies
4. List outstanding commitments and what should not be copied into the handoff

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Minimal handoff summary
- First-day readiness checklist
- Open commitments and owners
- Data excluded from transfer

## Example prompt

> Create a minimal onboarding handoff for a new analyst, excluding interview notes that the hiring manager does not need.

## Edge cases and failure handling

- Do not transfer sensitive interview notes or irrelevant personal data
- Accommodation data should use restricted approved processes
- Check local retention policy.

## Quality and safety checks

- [ ] Only necessary data is included
- [ ] Offer terms are confirmed
- [ ] Restricted data is excluded.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
