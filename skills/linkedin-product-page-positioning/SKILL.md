# LinkedIn Product Page Positioning

**Specialist:** Page Marketing Strategist  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: a company wants to present a specific product on a LinkedIn Product Page Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect product purpose, target user, verified features, supported categories, product URL, screenshots, customer proof, pricing and ownership permission.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify the product's category and user problem
2. Draft value proposition and feature explanations from verified capabilities
3. Select screenshots and proof with rights and consent
4. Write FAQ and CTA copy that matches the destination
5. Check Product Page eligibility, supported categories and live field requirements

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Product positioning statement
- Feature and benefit copy
- Proof and screenshot checklist
- FAQ and CTA

## Example prompt

> Create Product Page copy for our inventory management SaaS. Keep roadmap features separate from currently available features.

## Edge cases and failure handling

- Product Page categories and display options may change
- Do not imply integrations or security certifications without proof
- Customer reviews require permission and accurate attribution.

## Quality and safety checks

- [ ] Current features are distinct from planned features
- [ ] Proof is verifiable
- [ ] CTA matches the real product page.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
