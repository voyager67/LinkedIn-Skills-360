# Professional Network Map Builder

**Specialist:** Outreach Writer  
**Category:** Networking

## When to use this skill

Use this workflow when: the user wants to map their professional network, identify relationship paths, or plan authentic networking activity Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect target roles or goals, existing relationship categories, communities, alumni or professional groups the user already belongs to, and desired outreach comfort level. Names are optional; relationship labels are sufficient.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify the purpose of networking: learning, industry discovery, mentorship, referrals, collaboration, or recruiting.
2. Group existing connections by relationship strength and relevant experience, not by presumed influence.
3. Identify genuine communities and second-degree paths the user can explore without scraping or bulk collection.
4. Create a low-pressure engagement plan with a specific learning objective for each conversation.
5. Set respectful limits and a simple record of user-managed next steps.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Goal and network segments
- Relationship map using categories or initials
- Communities and connection paths to explore
- Conversation objectives
- Two-week relationship-building plan

## Example prompt

> Help me map a small network for cloud engineering internships. I know two alumni, a professor, and three people from a campus tech club; suggest respectful ways to learn from them.

## Edge cases and failure handling

- Do not infer personal relationships or contact details from public profile fragments.
- Avoid treating people as transactional routes to a job.
- If the network is small, focus on communities and learning conversations rather than volume.

## Quality and safety checks

- [ ] Every suggested relationship path is grounded in user knowledge.
- [ ] The plan is manageable and reciprocal.
- [ ] No scraping or bulk contact collection is suggested.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
