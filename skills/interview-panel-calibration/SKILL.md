# Interview Panel Calibration Guide

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a hiring panel wants to align on scorecard interpretation before or after candidate interviews Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect role criteria, rubric anchors, anonymized sample evidence, interviewer roles, and any observed scoring differences.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Review what each score anchor means with concrete job-related examples
2. Practice applying anchors to the same sample
3. Identify ambiguous criteria and revise before interviews
4. In debrief, distinguish observed evidence from inference and resolve disagreements transparently

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Calibration agenda
- Anchor examples
- Ambiguity and bias checks
- Debrief decision record template

## Example prompt

> Help calibrate a panel that interprets “strategic thinking” differently for a senior analyst role.

## Edge cases and failure handling

- Do not calibrate by comparing candidates' personal backgrounds
- Scores are not objective truth
- Escalate unresolved rubric defects.

## Quality and safety checks

- [ ] Anchors are observable and role-specific
- [ ] Disagreements are documented
- [ ] No false precision.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
