# Weekly Job Search Sprint Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to organize a manageable weekly cycle of job discovery, applications, networking, and interview practice Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect hours available, target roles, active applications, upcoming deadlines, energy constraints, and the previous week's results.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Choose a realistic weekly capacity and define one priority outcome
2. Allocate blocks to search, fit review, tailored applications, networking, and preparation
3. Set measurable process goals under the user's control
4. Add a weekly reflection and reprioritization rule

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Weekly calendar/block plan
- Priority list and time budget
- Process measures
- Weekly retrospective prompts

## Example prompt

> Plan a 6-hour job-search sprint this week around college classes and two pending applications.

## Edge cases and failure handling

- Avoid arbitrary application quotas that reduce quality
- Account for rest, accessibility, exams, and caring responsibilities
- Do not treat low response rates as personal failure.

## Quality and safety checks

- [ ] Plan fits the stated time budget
- [ ] Targets are controllable and realistic
- [ ] Sensitive context is not exposed.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
