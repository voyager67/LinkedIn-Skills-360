# Professional Cold Outreach Writer

**Specialist:** Outreach Writer  
**Category:** Networking

## When to use this skill

Use this workflow when: the user wants to write a first professional message to someone they do not know, including a hiring manager, practitioner, founder, or potential collaborator Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect recipient role and relevant context, reason for contacting, user's brief introduction, value or specific question, desired next step, and any relationship boundaries.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a recipient-centred reason for the message.
2. Verify the personalization detail from a reliable source or mark it for user confirmation.
3. Draft a clear opening, concise context, one relevant question or offer, and a graceful close.
4. Create a follow-up only when appropriate and space it respectfully; do not imply urgency.
5. Check that the message is not deceptive, overfamiliar, manipulative, or a disguised mass template.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Subject or opening line when appropriate
- First message
- Optional follow-up with suggested interval and stop condition
- Personalization evidence and facts to verify

## Example prompt

> Write a concise cold message to a product manager whose public talk I watched. Ask one thoughtful question about moving from engineering to product; don't ask for a job.

## Edge cases and failure handling

- If recipient context is unavailable, use a transparent, generic opening instead of invented personalization.
- For sensitive or high-volume outreach, recommend a more selective and respectful approach.
- If there has been no response after a courteous follow-up, recommend stopping.

## Quality and safety checks

- [ ] No fake relationship, endorsement, or familiarity.
- [ ] One primary ask and an easy way to decline.
- [ ] No mass messaging or automated sending.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
