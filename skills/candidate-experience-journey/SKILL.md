# Candidate Experience Journey Designer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to improve the candidate experience from first contact through interview, decision, and closure Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect stages, candidate personas/access needs, touchpoints, timing, communication examples, feedback sources and process constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map each touchpoint from candidate perspective
2. Identify friction, uncertainty, repetition and accessibility gaps
3. Draft practical improvements with owners and service standards
4. Define feedback questions and a review cadence

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Candidate journey map
- Friction points and priority fixes
- Communication standards
- Candidate feedback loop

## Example prompt

> Audit our recruitment journey for a graduate engineering role and recommend improvements.

## Edge cases and failure handling

- Do not collect sensitive candidate feedback beyond what is needed
- Small response samples may not represent all candidates
- Do not promise process guarantees without team agreement.

## Quality and safety checks

- [ ] Journey includes rejection and withdrawal paths
- [ ] Improvements are actionable
- [ ] Accessibility is considered.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
