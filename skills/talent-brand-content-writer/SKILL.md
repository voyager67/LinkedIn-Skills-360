# Recruiting and Talent Brand Content Writer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a talent team wants LinkedIn content about roles, employee learning, recruiting events, or workplace practices Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for target candidate audience, approved facts, employee participation, role details, source assets, tone and review owner.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Choose an informative candidate question to answer
2. Draft content around real work, people or process
3. Verify all employee quotes and permission for media
4. Add a clear but low-pressure candidate next step and review for exaggerated claims

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Content brief
- LinkedIn post draft
- Source and consent checklist
- Candidate CTA

## Example prompt

> Write a LinkedIn post introducing our engineering apprenticeship program using only these confirmed program details.

## Edge cases and failure handling

- Do not write fake employee stories or unapproved promises
- Disclose paid/incentivized content
- Avoid suggesting guaranteed job outcomes.

## Quality and safety checks

- [ ] Content is evidence-led
- [ ] People consent is explicit
- [ ] Role details match the approved posting.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
