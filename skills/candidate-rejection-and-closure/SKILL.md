# Candidate Rejection and Closure Writer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to write a respectful rejection, hold, withdrawal, or process-closure communication Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for stage, confirmed decision status, approved feedback policy, actual reason that may be shared, timing, and any future consideration.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Confirm decision and communication authority
2. Choose a transparent level of detail consistent with policy
3. Draft a respectful message that avoids unsupported or discriminatory explanations
4. Provide closure, next-step and data-retention language where approved

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Candidate message
- Feedback option if permitted
- Internal closure checklist

## Example prompt

> Write a respectful rejection after the final interview; provide concise role-related feedback that we can substantiate.

## Edge cases and failure handling

- Never invent feedback or imply future consideration without basis
- Do not disclose panel debate or other candidates' information
- Check local retention and notice policies.

## Quality and safety checks

- [ ] Message is accurate and humane
- [ ] Feedback is factual and job-related
- [ ] No false promise.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
