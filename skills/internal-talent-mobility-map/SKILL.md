# Internal Talent Mobility Map

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: an HR or talent team wants to map internal role pathways and adjacent skills for employee mobility Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for anonymized role families, skills frameworks, development paths, vacancies or future needs, and governance constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map current role skills to adjacent role requirements
2. Identify transferable competencies and development evidence
3. Design voluntary career conversations and learning pathways
4. Flag data and access constraints before using employee-level information

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Role adjacency map
- Skill bridge matrix
- Development pathways
- Data governance and validation questions

## Example prompt

> Create an internal mobility map between technical support, QA, and product operations roles using this anonymized skills framework.

## Edge cases and failure handling

- Do not infer career intent or performance from employee data
- Do not make automated promotion or redundancy recommendations
- Use aggregate or consented data.

## Quality and safety checks

- [ ] Paths are framed as possibilities, not promises
- [ ] Employee choice is central
- [ ] No unsupported individual inference.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
