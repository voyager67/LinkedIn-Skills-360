# Recruiter Communication Calendar

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a recruiter wants to coordinate candidate updates and hiring-team communications across a live process Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for stages, expected response times, decision owners, interview schedule, candidate preferences, and communication policies.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Map candidate touchpoints to process stages
2. Set a predictable update cadence and an owner for every message
3. Prepare approved templates for invitations, reminders and delays
4. Include escalation rules when timelines slip or feedback is missing

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Communication journey map
- Stage-by-stage calendar
- Message templates
- SLA/ownership and escalation checklist

## Example prompt

> Create a communication plan for a three-stage engineering interview process with a one-week target turnaround.

## Edge cases and failure handling

- Do not promise deadlines the team cannot meet
- Respect candidate communication preferences
- Avoid sharing other candidates' information.

## Quality and safety checks

- [ ] Every touchpoint has an owner
- [ ] Templates are truthful and inclusive
- [ ] Delay handling is planned.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
