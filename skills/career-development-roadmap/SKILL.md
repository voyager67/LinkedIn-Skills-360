# Career Development Roadmap

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants a longer-term career roadmap with milestones, evidence projects, learning, and networking Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect current level, target role, timeframe, available weekly hours, interests, constraints, and evidence of current strengths.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Clarify the target role and the kind of work it entails
2. Map present strengths and evidence gaps to role competencies
3. Prioritize learning and proof-building milestones
4. Set quarterly checkpoints and revise based on real feedback and market signals

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Target role profile
- Competency gap map
- 30/60/90-day and quarterly milestones
- Evidence and review metrics

## Example prompt

> Create a 12-month roadmap from second-year IT student to internship-ready backend developer.

## Edge cases and failure handling

- Do not promise a job outcome
- Avoid unrealistic study hours or paid-course pressure
- Update assumptions when role expectations change.

## Quality and safety checks

- [ ] Milestones are measurable and feasible
- [ ] Learning is linked to evidence
- [ ] Uncertainty is explicit.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
