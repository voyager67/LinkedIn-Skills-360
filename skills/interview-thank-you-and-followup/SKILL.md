# Interview Thank-you and Follow-up Writer

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to send a post-interview thank-you, status check, or follow-up on a real hiring process Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect interview date, recipient, real topics discussed, next-step timeline, user's interest, and any agreed action.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Use one or two genuine conversation details
2. Write a brief thank-you that reinforces relevant evidence without repeating the resume
3. For a status check, reference the agreed timeline and ask politely
4. Define a reasonable follow-up limit and stop condition

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Thank-you message
- Status follow-up if needed
- Timeline and stop condition

## Example prompt

> Draft a thank-you to my interviewer, mentioning our discussion of incident response and my project experience.

## Edge cases and failure handling

- Do not imply the interviewer promised an offer
- Avoid multiple follow-ups in short intervals
- Do not invent conversation details.

## Quality and safety checks

- [ ] Message references true discussion
- [ ] Tone is concise and professional
- [ ] Follow-up respects stated timelines.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
