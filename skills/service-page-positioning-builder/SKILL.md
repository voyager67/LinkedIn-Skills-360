# Services Page Positioning Builder

**Specialist:** Profile Optimizer  
**Category:** Profile and reputation

## When to use this skill

Use this workflow when: the user wants to position freelance, consulting, or professional services on a LinkedIn Services Page Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for service scope, ideal client, geography, delivery model, proof, exclusions, capacity, pricing preferences, and permitted portfolio examples.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define a narrow client problem and service outcome
2. Turn delivery into clear packages or scope statements without promising unsupported results
3. Draft service descriptions, proof points, FAQs, and intake questions
4. Check availability of the feature and its current fields in the user's account/region

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Service positioning statement
- Service descriptions and scope boundaries
- Proof and FAQ copy
- Client qualification questions

## Example prompt

> Create a Services Page for my freelance UI design work aimed at early-stage SaaS teams.

## Edge cases and failure handling

- Feature eligibility and settings can vary
- Avoid guarantees, unlicensed professional claims, and misleading client logos
- Separate estimates from fixed commitments.

## Quality and safety checks

- [ ] Scope and exclusions are explicit
- [ ] Claims have proof or are marked for confirmation
- [ ] The user verifies current platform availability.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
