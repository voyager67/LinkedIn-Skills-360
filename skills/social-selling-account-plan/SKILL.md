# Social Selling Account Plan

**Specialist:** Sales Development Strategist  
**Category:** Sales, partnerships and business development

## When to use this skill

Use this workflow when: a sales professional wants to build a respectful LinkedIn engagement plan for a named target account Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect account goals, product fit, public business triggers, known stakeholder roles, existing relationship, time horizon, and outreach permissions.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define the account hypothesis and desired learning
2. Map relevant public stakeholders by function rather than scraping personal profiles
3. Plan useful content or conversation contributions that do not misrepresent expertise
4. Set human follow-up triggers and stop conditions

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Account engagement thesis
- Stakeholder role map
- Value-first engagement plan
- Manual activity and learning log

## Example prompt

> Plan a 30-day social-selling approach for a SaaS product targeting HR operations teams.

## Edge cases and failure handling

- Do not automate views, likes, comments or messages
- Avoid repeated contact after silence or refusal
- Do not use sensitive personal attributes to target prospects.

## Quality and safety checks

- [ ] Outreach is relevant and individualized
- [ ] Value precedes the ask
- [ ] Activity log contains only necessary data.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
