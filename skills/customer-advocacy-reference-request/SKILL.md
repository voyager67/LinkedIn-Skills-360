# Customer Advocacy and Reference Request

**Specialist:** Sales Development Strategist  
**Category:** Sales, partnerships and business development

## When to use this skill

Use this workflow when: a professional wants to request a customer reference, testimonial, or public endorsement based on real delivery Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for customer relationship, confirmed outcome, permission history, preferred channel, review policy, and the specific advocacy requested.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Check whether the customer is eligible and willing under company policy
2. Choose the least burdensome request that fits the relationship
3. Provide factual prompts and transparent disclosure expectations
4. Create a consent and approval process before publishing any quote or logo

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Permission request
- Optional testimonial prompts
- Disclosure/approval checklist
- Alternative private reference option

## Example prompt

> Draft a polite request for a customer to approve a short public testimonial about our implementation support.

## Edge cases and failure handling

- Do not offer undisclosed incentives or pressure a customer
- Never fabricate or edit a quote to change meaning
- Check contractual restrictions.

## Quality and safety checks

- [ ] Customer approves final wording and attribution
- [ ] Incentives are disclosed as required
- [ ] No testimonial is published without permission.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
