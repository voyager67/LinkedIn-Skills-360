# LinkedIn Lead Gen Form Designer

**Specialist:** LinkedIn Ads Strategist  
**Category:** Marketing and learning

## When to use this skill

Use this workflow when: the user wants to design or review a LinkedIn Lead Gen Form and its value exchange Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect offer, audience, form objective, landing-page alternative, required fields, privacy notice, consent language, routing process, and lead qualification criteria.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define what the user receives in exchange for contact details
2. Keep form fields to the minimum needed for the follow-up
3. Draft clear field labels, context, privacy notice and confirmation message
4. Design a transparent qualification and response workflow
5. Check current Campaign Manager form requirements and account permissions

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Form proposition and field plan
- Intro and confirmation copy
- Privacy/consent review questions
- Lead routing and response SLA

## Example prompt

> Create a Lead Gen Form for a downloadable B2B cybersecurity checklist. Keep fields minimal and make the value exchange clear.

## Edge cases and failure handling

- Profile-prefilled form data still requires transparent use and approved handling
- Do not ask for sensitive personal data without a lawful necessity and process
- Form features and permissions may vary.

## Quality and safety checks

- [ ] The offer is specific and deliverable
- [ ] Every field has a reason
- [ ] Privacy and follow-up ownership are explicit.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
