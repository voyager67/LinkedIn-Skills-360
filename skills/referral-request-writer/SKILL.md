# Referral Request Writer

**Specialist:** Outreach Writer  
**Category:** Networking

## When to use this skill

Use this workflow when: the user wants to request a referral, employee introduction, or internal role guidance from an existing professional connection Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect relationship strength, recipient's role, target job link or ID, user's fit evidence, timing, and whether the recipient has offered help. Include resume only when the user intends to share it.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Assess whether the relationship and context make a direct referral ask reasonable.
2. Summarize why the user is interested in the role and how their evidence aligns.
3. Draft a permission-based message that makes the request easy to decline.
4. Offer a lower-pressure alternative such as asking for advice or asking whether the person is comfortable referring.
5. Provide a short evidence summary the recipient can use only if they choose to help.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Recommended referral message
- Lower-pressure alternative
- Role and fit summary
- Attachment or link checklist
- Follow-up boundary

## Example prompt

> Write a referral request to a former internship teammate for a junior analyst opening at their company. I meet three listed requirements and want to make it easy for them to say no.

## Edge cases and failure handling

- Do not imply the recipient promised a referral unless that is stated.
- If relationship is weak, recommend a brief informational request first.
- Never manufacture a referral, endorsement, or internal recommendation.

## Quality and safety checks

- [ ] The ask is respectful and optional.
- [ ] Role fit is described accurately.
- [ ] The message does not pressure the recipient or assume entitlement.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
