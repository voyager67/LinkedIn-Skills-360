# Cover Letter Writer

**Specialist:** Outreach Writer  
**Category:** Search and applications

## When to use this skill

Use this workflow when: the user asks for a tailored cover letter or concise application letter for a specific job Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect job description, resume or strongest evidence, motivation for the company/role, tone, length, and any named recipient if known. Do not invent a referral or relationship.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify the employer's actual role needs from the posting.
2. Select two or three pieces of evidence that demonstrate relevant capability.
3. Connect the user's motivation to specific, verified information about the role or organization.
4. Draft a concise opening, evidence-led middle, and professional close.
5. Check for unsupported claims, generic praise, repetition of the resume, and unnecessary personal disclosure.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Tailoring rationale
- Cover letter draft
- Claims needing confirmation
- Optional shorter application-text version

## Example prompt

> Write a tailored cover letter for this product analyst internship using my project experience and the company's public product information. Do not claim I have used their product professionally.

## Edge cases and failure handling

- If employer research is not supplied, keep motivation grounded in the job posting and mark any company-specific detail to verify.
- If no recipient is known, use a neutral greeting.
- For career transitions, show transferable evidence rather than apologize for the transition.

## Quality and safety checks

- [ ] Every claim is supported by supplied evidence.
- [ ] The letter is specific to the role without fake familiarity.
- [ ] Tone is professional, concise, and human.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
