# Career Fair Networking and Follow-up

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to prepare for a LinkedIn-connected career fair, employer event, or recruiting expo Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect event, participating employers, target roles, attendee context, profile/resume summary, and any real conversations or notes.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Prioritize employers by role fit and research each from public material
2. Create a short introduction and two role-relevant questions
3. Prepare a consent-aware note-taking approach
4. Draft personalized follow-ups only from actual conversations and set a no-response stop point

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Employer priority list
- 20-second introduction
- Questions by company
- Follow-up drafts tied to conversation notes

## Example prompt

> Help me prepare for a university career fair with these five participating employers and draft follow-ups after the event.

## Edge cases and failure handling

- Do not imply a conversation took place when none did
- Respect attendee privacy and event rules
- Avoid bulk connection requests.

## Quality and safety checks

- [ ] Follow-ups reference true conversation details
- [ ] Requests are specific and low pressure
- [ ] No mass outreach.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
