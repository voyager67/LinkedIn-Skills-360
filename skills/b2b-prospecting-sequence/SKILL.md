# B2B Prospecting Message Sequence

**Specialist:** Sales Development Strategist  
**Category:** Sales, partnerships and business development

## When to use this skill

Use this workflow when: the user wants a short, personalized B2B LinkedIn outreach sequence to a business contact Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for the business case, target role, verified trigger, true prior relationship, offer relevance, proof, desired action, and jurisdiction/platform constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Confirm a credible reason the recipient may care
2. Draft a concise first contact with a single low-friction question
3. Create limited follow-ups that add new useful context rather than repeating the pitch
4. Set a clear stop point and comply with applicable channel/consent rules

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Personalization evidence note
- Initial message
- Up to two value-adding follow-ups
- Stop/opt-out rule

## Example prompt

> Draft a respectful message to an operations director about our order reconciliation software using this public company announcement.

## Edge cases and failure handling

- No bulk identical messaging or auto-send
- Do not fabricate mutual connections, urgency, customer proof, or prior contact
- Legal requirements depend on jurisdiction and channel.

## Quality and safety checks

- [ ] Each message is grounded in a real business reason
- [ ] Follow-ups add value
- [ ] Recipient can decline easily.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
