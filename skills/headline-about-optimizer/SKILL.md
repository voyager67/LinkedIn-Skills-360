# Headline and About Optimizer

**Specialist:** Profile Optimizer  
**Category:** Profile

## When to use this skill

Use this workflow when: the user wants a LinkedIn headline, About section, positioning statement, or rewrite of profile introduction Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect target role or audience, current headline/About if available, relevant strengths, proof points, preferred tone, geographic or industry context, and any character limit the user wants observed.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Extract the user's actual role direction, strongest relevant evidence, audience, and differentiator.
2. Identify vague claims, jargon, keyword gaps, and claims that need proof.
3. Draft three headline directions with different emphasis: role clarity, evidence, and audience value.
4. Write an About section with a clear opening, credible background, relevant proof, focus areas, and a low-pressure next step.
5. Compare options against clarity, authenticity, search relevance, and factual support; recommend one with trade-offs.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Positioning statement
- Three headline options
- Recommended headline and rationale
- About section draft
- Keywords naturally incorporated
- Placeholders and facts requiring confirmation

## Example prompt

> Create three LinkedIn headline options and an About section for a second-year computer science student seeking software internships. Use my coursework and two projects; do not invent work experience.

## Edge cases and failure handling

- For students and career changers, emphasize projects, transferable evidence, and learning without implying seniority.
- If metrics are missing, use concrete scope or leave a placeholder rather than fabricating impact.
- Do not promise profile visibility or recruiter response improvements.

## Quality and safety checks

- [ ] Opening clearly identifies the user's focus and audience.
- [ ] Keywords read naturally rather than as a keyword dump.
- [ ] Claims are traceable to user-provided evidence.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
