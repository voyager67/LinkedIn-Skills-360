# Structured Interview Plan and Panel Designer

**Specialist:** Recruiter Operations Partner  
**Category:** Recruiting and talent operations

## When to use this skill

Use this workflow when: a hiring team wants a structured interview loop that assesses approved job-related competencies Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect role outcomes, competency framework, interview stages, panel availability, time limits, accommodation needs, and assessment constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Allocate distinct competencies to stages to avoid redundant interviews
2. Write standardized prompts and follow-up probes
3. Define evidence anchors and interviewer responsibilities
4. Check workload, accessibility, candidate prep, and decision flow

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Interview loop and stage objectives
- Question bank and probes
- Interviewer assignment matrix
- Candidate preparation and accessibility notes

## Example prompt

> Design a four-stage structured interview plan for a mid-level product designer role.

## Edge cases and failure handling

- Avoid trick questions and irrelevant puzzles
- Do not ask unlawful or unnecessary personal questions
- Provide reasonable process flexibility.

## Quality and safety checks

- [ ] Each stage tests a distinct job-related area
- [ ] Questions map to competencies
- [ ] Panel load is proportionate.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
