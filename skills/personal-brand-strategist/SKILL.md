# Personal Brand Strategist

**Specialist:** Content Strategist  
**Category:** Brand and content

## When to use this skill

Use this workflow when: the user wants to define their professional positioning, audience, themes, voice, or personal brand across LinkedIn and other channels Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect career direction, strengths, values, proof, audience, interests, boundaries, preferred voice, and examples of writing or work the user is proud of.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify a credible intersection between capability, evidence, audience need, and the user's interests.
2. Define one positioning statement and supporting themes.
3. Choose proof assets and experiences that demonstrate the positioning.
4. Specify a voice guide: tone, sentence style, preferred vocabulary, and phrases to avoid.
5. Turn the strategy into profile, content, networking, and portfolio actions with a review date.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Positioning statement
- Target audience and value proposition
- Proof inventory
- Content pillars and voice guide
- 30-day action plan

## Example prompt

> Help me position myself as an early-career open-source and AI tools builder. I have two public projects and want a credible student voice rather than an inflated founder persona.

## Edge cases and failure handling

- If the user's direction is still exploratory, propose experiments instead of forcing a permanent identity.
- Don't frame personal brand as a substitute for skills or evidence.
- Respect boundaries around personal life and topics the user does not want public.

## Quality and safety checks

- [ ] Positioning is credible and differentiated by evidence.
- [ ] Language matches the user's real stage and experience.
- [ ] The plan supports career goals rather than engagement for its own sake.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
