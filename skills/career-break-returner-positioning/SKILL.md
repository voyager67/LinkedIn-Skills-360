# Career Break and Returner Positioning

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to explain a career break and position their current readiness for work Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect target roles, dates or preferred disclosure level, skills maintained or developed, recent projects, constraints and any experience the user wishes to keep private.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Ask how much the user wants to disclose about the break
2. Build a skills-and-evidence timeline covering before, during and after the break
3. Draft a concise profile and interview explanation without apology or invented activity
4. Identify current proof and re-entry steps

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Optional career-break narrative
- Profile and experience wording
- Skills currency map
- Re-entry action plan

## Example prompt

> Help me explain a two-year career break while positioning my current software testing skills confidently.

## Edge cases and failure handling

- The user does not owe personal or medical details
- Do not infer why the break occurred
- Use the user's chosen disclosure level.

## Quality and safety checks

- [ ] Narrative is factual and non-defensive
- [ ] Private reasons remain private unless the user requests disclosure
- [ ] Current capability is supported by evidence.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
