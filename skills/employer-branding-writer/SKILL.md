# Employer Branding Writer

**Specialist:** Recruiter Assistant  
**Category:** Recruiting

## When to use this skill

Use this workflow when: the user wants authentic employer-brand content, a careers-page narrative, employee story, or candidate-facing overview Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect real employee or team perspectives, approved values, role context, proof points, audience, channels, consent status, and any details that must remain confidential.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify the candidate audience and the real questions they need answered.
2. Gather approved evidence about work, development, leadership, inclusion, benefits, and day-to-day expectations.
3. Draft a narrative using real voices and specific examples with consent.
4. Avoid unsupported superlatives, generic culture claims, and promises the organization cannot substantiate.
5. Create a fact-check and approval checklist for HR, legal, and the people quoted.

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Audience and message strategy
- Employer-brand narrative or content draft
- Proof points and source owners
- Claims requiring approval
- Consent and publication checklist

## Example prompt

> Draft an employer-brand post describing our early-career mentorship program. Use the actual program details I provide; don't claim everyone gets promoted quickly.

## Edge cases and failure handling

- If there is no evidence for a culture claim, omit it or label it as a goal rather than a fact.
- Get permission before using employee names, quotes, images, or identifiable stories.
- Ensure benefits and policies are current for the relevant location.

## Quality and safety checks

- [ ] Claims are verifiable and approved.
- [ ] Employee stories have consent.
- [ ] The narrative does not overpromise the candidate experience.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
