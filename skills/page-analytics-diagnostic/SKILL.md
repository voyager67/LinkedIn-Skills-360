# LinkedIn Page Analytics Diagnostic

**Specialist:** Content Strategist  
**Category:** Creator, content and company presence

## When to use this skill

Use this workflow when: a Page owner wants to interpret LinkedIn company-page content, follower, visitor, or search appearance analytics Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for metric export/screenshots, date range, content type, audience or segment, campaign context, and the decision the analysis supports.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define the exact metric and reporting window
2. Separate paid, boosted and organic activity where data allows
3. Compare like-for-like periods and content types
4. Identify plausible explanations, limitations and experiments rather than asserting causation

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Metric definitions and data-quality notes
- Trend summary
- Content/audience hypotheses
- Recommended controlled experiments

## Example prompt

> Analyze these LinkedIn Page analytics for the last quarter and identify which content themes deserve follow-up.

## Edge cases and failure handling

- Metric definitions and UI may change
- Small samples and paid amplification can distort comparisons
- Do not equate reach with business outcomes.

## Quality and safety checks

- [ ] Time windows and denominators are clear
- [ ] Correlation is not described as causation
- [ ] Recommendations include a way to test them.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
