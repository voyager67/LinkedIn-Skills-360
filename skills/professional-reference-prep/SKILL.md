# Professional Reference Preparation

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user wants to select, brief, or prepare professional references for a job or opportunity Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for role, reference requirements, relationship history, permission already obtained, contact preferences, and any confidential details.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Identify people with direct and relevant knowledge of the user's work
2. Request permission before sharing contact information
3. Prepare a concise factual context brief and likely topic areas
4. Confirm availability and thank the reference without scripting their claims

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Reference shortlist criteria
- Permission request
- Reference briefing note
- Thank-you checklist

## Example prompt

> Help me ask two former teammates to serve as references and prepare a factual briefing note.

## Edge cases and failure handling

- Never share a person's contact details without consent
- Do not coach someone to lie or reveal confidential information
- Do not list a reference who has not agreed.

## Quality and safety checks

- [ ] Permission is explicit
- [ ] Briefing is factual and not a scripted testimonial
- [ ] Private contact information is handled carefully.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
