# Partnership Outreach Planner

**Specialist:** Sales Development Strategist  
**Category:** Sales, partnerships and business development

## When to use this skill

Use this workflow when: the user wants to identify and approach potential collaborators, ecosystem partners, or channel partners on LinkedIn Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Ask for partnership thesis, mutual audience/value, partner type, proof of delivery, desired pilot, stakeholders, and constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Define the mutual benefit and why this partner is relevant
2. Map organization-level stakeholders and public partner signals
3. Draft a short collaborative introduction and discovery agenda
4. Propose a low-risk pilot with scope, success measures and exit conditions

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- Partner fit hypothesis
- Stakeholder roles
- Outreach message
- Pilot concept and success measures

## Example prompt

> Create a partnership outreach plan between an edtech startup and university coding clubs.

## Edge cases and failure handling

- Do not imply existing partnerships or permissions
- Protect confidential commercial terms
- Avoid claiming exclusivity without agreement.

## Quality and safety checks

- [ ] Mutual value is explicit
- [ ] Pilot outcomes are measurable and realistic
- [ ] No partnership is represented as confirmed.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
