# First 90 Days Planner

**Specialist:** Job Hunter  
**Category:** Job search and career operations

## When to use this skill

Use this workflow when: the user is starting a new job or transitioning into a role and wants a structured first-90-days plan Do not activate it merely because a related keyword appears in unrelated text.

## Inputs to collect

Collect role, responsibilities, manager expectations, team context, start date, performance measures, and known constraints.

Ask only for missing information that materially changes the recommendation. State assumptions when a first-pass answer can be made without blocking.

## Workflow

1. Separate what must be learned from what must be delivered
2. Plan listening, relationship-building, systems onboarding and early wins
3. Define 30/60/90-day outcomes and dependencies
4. Prepare weekly check-ins and a risk/assumption log

## Output format

Return the following sections, adapting them to the task rather than forcing empty sections:

- 30/60/90-day roadmap
- Stakeholder and learning plan
- Early deliverables and measures
- Questions for manager

## Example prompt

> Build a 90-day onboarding plan for a new junior product analyst joining a fintech team.

## Edge cases and failure handling

- Do not assume access to internal systems or authority
- Treat example milestones as draft until manager agreement
- Avoid promising results before understanding constraints.

## Quality and safety checks

- [ ] Goals are role-specific and revisable
- [ ] Dependencies are visible
- [ ] Manager confirmation is included.

## Completion rule

Finish with a concise next action the user can take. Never imply that LinkedIn, an employer, a recruiter, an applicant tracking system, or a hiring decision-maker has been contacted or updated by this skill.
