# Claude Code

Use the current Claude Code skill installation/discovery rules documented by Anthropic. Copy only the needed folders from `skills/` into a supported skills directory. Keep the entire folder so the `SKILL.md` and any supporting files remain together.

For a one-off task, open the selected `SKILL.md`, paste or attach it, and provide the requested inputs. For cross-workflow tasks, also provide `agents/orchestrator.md` and the selected specialist prompt.

Do not assume every environment supports the same directory, slash command naming or automatic loading. Do not add LinkedIn login credentials, cookies, browser automation or scraping tools to the workflow.
