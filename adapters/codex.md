# OpenAI Codex

The skills are plain Markdown and can be supplied as task context. Where the installed Codex version supports reusable skill directories, copy the selected `skills/<name>/` folders to a documented location and verify that Codex discovers them.

For a single task, attach or paste the `SKILL.md`. For routing, include `agents/orchestrator.md` and the needed specialist. When delegation is unavailable, execute the same workflow sequentially.

Check current Codex documentation for supported locations and invocation behaviour. This adapter does not claim persistent auto-loading for all clients or plans.
