# Gemini and other AI hosts

Use the core workflow by attaching or pasting the selected `SKILL.md` wherever the model accepts detailed instructions. If the host supports project-level instructions or reusable skills, follow its current documentation and install the folder in the supported location.

The Markdown content is intentionally not tied to a provider API. Models may differ in context size, instruction-following, file handling, browsing, memory, tools and agent delegation. Keep the output contract intact, but review important factual and safety requirements after each run.

For local or open-weight models, keep inputs short enough for the context window and avoid sending sensitive resumes, inbox messages or candidate data to an untrusted endpoint.
