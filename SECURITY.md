# Security policy

## Scope

This repository is primarily Markdown guidance and templates. It is not an authentication system, LinkedIn integration, candidate database, or hosted application.

## Reporting a vulnerability

Please do not disclose sensitive details in a public issue. Use GitHub's private vulnerability reporting feature when enabled for this repository, or contact the maintainers privately through the contact information on the repository profile.

Include the affected path, impact, reproduction steps, and a suggested mitigation when possible. Do not include real credentials, personal resumes, or candidate data.

## Data handling

- Do not commit API keys, passwords, access tokens, private resumes, contact lists, or candidate records.
- Treat prompts and source documents as potentially sensitive; redact unnecessary personal information before sharing with a model.
- Review host privacy, retention, and training settings before supplying personal or recruiting data.
- Report suspicious changes to templates or scripts that attempt to exfiltrate data or introduce hidden network calls.

## Supported versions

There are no release tags or versioned runtime packages. The default branch is the supported source of current documentation.
