# Example: Student profile refresh

**Audience:** Student / internship applicant

**Prompt to try**

> Use `student-career-launch` and `headline-about-optimizer`. I am a second-year engineering student seeking software internships. My evidence: coursework in data structures, a Python expense-tracker project, a two-person web app where I handled the frontend, and a campus coding club role. I have no formal internship yet. Draft a truthful headline, About section, and two project bullets. Mark every missing fact as a question; do not invent metrics or professional experience.

**What a good output should do:** reflect student seniority, distinguish project work from employment, and ask for proof rather than fabricate it.
